# 國中複習站（純 HTML 版）

不需要 Python 或任何伺服器，直接用瀏覽器開啟即可。

## 使用方式

1. 解壓縮 `review-html.zip`
2. 雙擊 `index.html`，用 Chrome、Edge 或 Firefox 開啟

## 檔案結構

```
review-html/
├── index.html       首頁（頁面骨架）
├── css/style.css    樣式
└── js/
    ├── content.js   課程內容（之後新增單元改這裡）
    └── app.js       路由、註冊登入、進度與成就邏輯
```

## 目前內容

- 七年級：五科共 32 單元，每個單元都有趣味開場與「你知道嗎？」冷知識（在 `js/lessons.js`）。
- 八、九年級：五科各 2 單元，共 20 單元（在 `js/content-8-9.js`）。
- 複習中心：閱讀講解後回答 3 題，全部答對才會記為已複習。確認後超過 7 天會提醒再複習。

## 新增單元

在 `js/content-8-9.js` 的 `add(...)` 中加入一筆單元，格式如下：

```javascript
{
  id: "math-8-3",                 // 格式：科目-年級-序號，須唯一
  title: "單元名稱",
  hook: "開場的生活情境",          // 趣味開場
  points: ["重點一", "重點二"],
  fun: "你知道嗎？冷知識",         // 趣味冷知識
  gen: ["linearFunc"],            // 出題產生器（js/quiz.js），可無限隨機出題
  bank: [["題目", "答案"]]         // 固定題庫（可留空 []）
}
```

- 每個單元至少要有 3 個不同題目（複習需要 3 題）。`gen` 會自動變化，`bank` 題目要夠多。
- 要新增自動出題的題型，在 `js/quiz.js` 的 `G` 或 `Object.assign(G, {...})` 中加入函式，回傳 `{ q: "題目", a: "答案" }`。
- 七年級的講解可以在 `js/lessons.js` 依 id 補上 `hook` 與 `fun`。

## 重要限制

- **資料存在瀏覽器本機**（localStorage）：帳號與學習紀錄只存在這台電腦的這個瀏覽器裡，換電腦或換瀏覽器看不到。清除瀏覽器資料也會遺失。
- **密碼安全性有限**：純前端無法做到伺服器端的安全保護，目前是用 SHA-256 加隨機鹽做雜湊，足以避免明文儲存，但不適合用於真正敏感的帳號。
- **若要跨裝置同步**，需要後端服務，例如 Firebase Authentication + Firestore，或 Supabase。
- 國文、社會主要靠固定題庫，題目數量有限，可以持續在 bank 中擴充。
- 教材內容請使用自行整理或可合法使用的素材，避免直接複製出版社課本內容。

## 重設資料

在瀏覽器開發者工具的 Console 輸入以下指令可清除所有本機帳號與紀錄：

```javascript
Object.keys(localStorage).filter(k => k.startsWith("crs_")).forEach(k => localStorage.removeItem(k));
```

## 功能總覽（目前版本）

- **三種難度**：基礎、進階、困難（混合）。數學、自然的題目數字範圍會隨難度變化；困難題會加入多步驟運算。
- **複習中心**：閱讀講解後回答 3 題確認複習，錯的題目會自動收進錯題本。
- **模擬考**：依年級、科目、題數、難度隨機抽題，交卷後逐題檢討，成績會記錄。
- **錯題本**：答錯的題目自動收錄，答對後移出。
- **連續學習天數**與成就。

## 關於題目來源

- 所有題目皆為依課綱主題原創，**不是**抄錄其他網站或出版社的題目。
- 題目的範圍與難度大致對應 108 課綱，但不同出版社的課本編排不同，使用前請對照自己的課本。
- 如果要練真正的會考題，請到大考中心官方網站（ceec.edu.tw）查詢歷屆國中教育會考試題與解答，這些是公開的官方資料。

## 管理員（只有你能設定）

管理員帳號不再提供網站內建註冊，只能由你自己設定：

1. 用瀏覽器打開 `tools/make-admin.html`。
2. 輸入管理員帳號與密碼（至少 8 字元），按「產生設定」。
3. 把產生的內容完整複製，取代 `js/admin-config.js`，存檔後重新整理網站。
4. 之後用該帳號登入，導覽列會出現「管理後台」。

後台功能：
- **帳號管理**：停用／啟用、重設密碼、刪除帳號（只限這台瀏覽器上的帳號）。
- **單元管理**：修改任何單元的開場提示、重點、冷知識與題庫（更改提示），也能隱藏單元。
- **新增單元**：新增章節與單元，自訂題庫。
- **影片管理**：貼上 YouTube 網址，嵌入到指定單元。
- **公告**：顯示在首頁頂部。
- **系統**：下載全部本機資料、清除自訂內容。

注意：這是純前端網站。管理員密碼以 SHA-256 雜湊存放，但設定檔是公開可讀的，所以密碼務必夠長。
要真正做到只有你能管理，需要後端（例如 Firebase Authentication）。

## 難度

基礎、進階、困難、魔王。魔王題只會出現在指定難度的練習與模擬考中，混合模式不會出現。

## YouTube 影片

- 每個單元下方都有「在 YouTube 搜尋」按鈕，會以「國中 科目 年級 單元名」搜尋。
- 管理員可以貼上確認過內容的影片網址，網站會直接嵌入播放。

## 題庫與題目語言（目前版本）

- **英文題庫、日文題庫**：導覽列與首頁可以進入，整批練習，全部題目為該語言，依難度隨機出題（各 18 題，會持續擴充）。
- **題目語言切換**：單元練習與模擬考可以選「中文」或「日文版」。
- **日文版覆蓋**：目前只有數學、自然、社會中的部分題型有日文版（共 12 個單元）。國文、英文、日文科目的單元尚未提供日文版，切換時會顯示「尚無日文版題目」。
